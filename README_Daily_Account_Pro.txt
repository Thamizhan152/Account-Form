DAILY ACCOUNT FORM PRO — STARTER PACKAGE

Included:
- Daily_Account_Form_Pro.html: responsive web application for mobile and computer browsers.
- Daily_Account_Professional.xlsx: Excel workbook with Transactions, Dashboard, and Category Report.

Web app features:
- Business and personal transaction types
- Opening balance, income, expense, and calculated closing balance
- Daily and monthly summaries
- Search and filters
- Export transactions and daily/monthly reports as Excel-compatible CSV
- JSON backup and import

How to run:
1. Download the HTML file or ZIP package.
2. Open the HTML file in a modern browser such as Chrome or Edge.
3. Records are stored in the browser on this device only. They do not sync automatically between devices.
4. Export CSV to open data in Excel. Use JSON backup to transfer data to another device.

Excel:
- Enter each transaction on a new row in Transactions.
- Dashboard shows daily and monthly totals.
- Category Report summarizes income and expense by category.
- Excel formulas are included; open in Excel or a compatible spreadsheet app.

Important:
This is a starter version, not a hosted cloud app. For true mobile+computer syncing, publish/host the app and connect a secure cloud database/login.
